# Copy Path (Zotero 8–10 plugin)

Copy the full path of an attachment's file to the clipboard.

## Usage

Right-click a file attachment, such as a PDF or EPUB, in the item list, then choose **Copy Path**.
The full path of the file is copied to the clipboard, for example:

```
/Users/you/Zotero/storage/ABCD1234/Smith - 2020 - Some Article.pdf
```

- With several attachments selected, choose **Copy Paths** to copy their paths one per line.
- This works for stored files (in Zotero's `storage` folder) and for linked files.
- The menu item doesn't appear for parent items, notes, or links to web pages.
